# Здоровье и хилки

В сцене `Assets/Scenes/Arena.unity` над шкалой здоровья героя отображается текущее и максимальное HP. На старте это 620 / 620: 62 деления по 10 HP. При повышении уровня максимум растёт вместе с ценой деления.

На арене размещены 10 красных зелий в объекте `MODE - Arena > Healing Pickups (editable)`. Зелье подбирается при касании, восстанавливает до 80 HP, но не тратится, если здоровье полное. После подбора оно вновь появляется через 45 секунд. Мёртвого героя зелье не воскрешает.

Чтобы настроить все зелья сразу, откройте `Assets/Prefabs/HealingPotion.prefab` и измените в компоненте `Healing Pickup` поля `Heal Amount` и `Respawn Seconds`. Можно передвигать, копировать или удалять отдельные экземпляры прямо в сцене. Для индивидуальных значений используйте override компонента на нужном экземпляре.

Исходный пиксельный рисунок: `Assets/Art/Source/Pickups/healing_potion.aseprite`. Игровой PNG: `Assets/Art/Imported/Pickups/healing_potion.png`. После изменения рисунка в Aseprite экспортируйте PNG по этому пути. `Tools/BuildHealingPickupArt.ps1` нужен только для пересоздания исходного варианта; его запуск перезапишет рисунок.
