# Звуки игры

В `Assets/Scenes/Arena.unity` на объекте `MODE - Arena` находится компонент `Game Sfx`. В нём можно заменить любой клип, отключить его, очистив поле, и настроить громкость героя, отдельную громкость шагов (`Footstep Volume`), громкость врагов, общую громкость и расстояние слышимости врагов. Файлы лежат в `Assets/Audio/Sfx`.

Подключены: шаги при движении, прыжок, рывок, взмах меча, подтверждение попадания, урон героя, подбор зелья, предупреждение и удар мага, атака кольцом, ловушка и запуск/взрыв бомбы Io. Для врагов с общей предупреждающей окружностью используется `Enemy Strike`. Одновременно звучат не более шести вражеских эффектов; далёкие враги не слышны. При сильных ударах музыка ненадолго становится чуть тише.

Все WAV синтезированы локально без чужих сэмплов. Их можно пересоздать командой `dotnet run --project Tools/OriginalSfx/OriginalSfx.csproj -c Release`. Команда перезаписывает WAV в `Assets/Audio/Sfx`, поэтому сначала сохраните вручную изменённые файлы под другими именами.

Шаги запускаются только во время движения и не чаще чем раз в 0.3 секунды. Звук меча играет при начале взмаха, звук попадания — не более одного раза за взмах при касании цели. Вражеские звуки запускаются при событиях атаки, а не каждый кадр анимации.
