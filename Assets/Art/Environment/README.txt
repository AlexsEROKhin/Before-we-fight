Оформление арены

Пять файлов .aseprite — редактируемые исходники; одноимённые PNG использует Unity.
forest_tree — новое дерево для этой арены. Старый импортированный спрайт дерева
в новом оформлении не используется.

В Arena.unity откройте WORLD - edit positions here > Forest Dressing (editable).
Там остались только деревья: каждое можно передвинуть или отключить отдельно.
Кусты, камни и трава из сцены убраны, но их исходники пока сохранены.
У каждого дерева есть BoxCollider2D на основании ствола с одинаковыми настройками:
Offset X = 0.01, Y = 0.29; Size X = 0.4, Y = 0.15 (как у Forest tree 02).
Крона остаётся проходимой.
В Arena у капсулы героя Offset Y = 0.115: её центр совпадает с ногами/тенью,
чтобы герой не упирался в ствол, когда его рисунок ещё у верхней части кроны.
Земля находится в редактируемом префабе Ground; площадь осталась 120 x 120.
Сейчас forest_floor — ровный коричневый тайл с редкими штрихами, как в образце.
Менять его можно в forest_floor.aseprite; мох и крупные пятна убраны.

Перекрытие героя и деревьев настроено без скрипта: в Project Settings > Graphics
прозрачные спрайты сортируются по оси Y. У PlayerVisual и всех Forest tree
одинаковый Order in Layer (0), а Sort Point — Pivot у основания дерева.
Если добавить ещё дерево, поставьте ему те же Sorting Layer, Order и Sort Point.
