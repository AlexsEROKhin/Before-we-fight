# Io в арене

Готовый префаб: `Assets/Prefabs/Io.prefab`. Его экземпляры стоят в группах
врагов сцены `Assets/Scenes/Arena.unity`. Начальная зона героя остаётся свободной.

## Что редактировать в Inspector

- `Io` → `IoEnemy`: максимальное здоровье, плавность и скорость полёта,
  `Minimum Io Distance` (сейчас 2.4 единицы) — расстояние между двумя Io,
  предпочитаемая дистанция, число/радиус/скорость бомб, интервалы атаки и
  восстановления. `IoVisual (editable)` — отдельный дочерний объект для
  покачивания, без перемещения хитбокса.
- `Io` → `IoTether`: дальность поиска и разрыва связи, лечение, бонус скорости,
  цвет и толщину линии. Основная линия и движущийся световой импульс создаются
  компонентом `LineRenderer` при запуске.
- `IoBomb.prefab` → `IoBomb`: контактный урон и его задержку, урон/радиус/задержку
  взрыва и скорость полёта. Круг бомбы — временный пиксельный placeholder;
  исходный спрайт Ио не изменён.

## Система здоровья союзников

На `RingCreep` и `MageCreep` добавлен `EnemySupportable`. Он использует их
существующее число попаданий до смерти, а не отдельную шкалу HP. В текущих
настройках 10 единиц лечения восстанавливают одно потерянное попадание.
Один союзник может иметь только одну связь Io: второй Io выберет другую цель
или подождёт. Лечение снижено до 5 единиц в секунду — одно потерянное
попадание восстанавливается примерно за 2 секунды, если связь не прервана.
Несколько связей не складывают бонус скорости: применяется только наибольший.
Эти два типа составляют группы врагов в текущей арене. Для запасных типов
врагов из других префабов понадобится такой же адаптер к их счётчику здоровья.

## Проверка

Команда для пакетной проверки: `Unity.exe -batchmode -projectPath <путь проекта>
-executeMethod IoSmokeTest.Run -logFile <путь лога>`.
Тест проверяет создание трёх бомб, уникальность выбранных союзников, +25% скорости, лечение,
отделение и исчезновение атакующей бомбы, очистку бомб и бонусов после гибели Ио.
